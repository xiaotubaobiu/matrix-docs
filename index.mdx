## 欢迎使用 Matrix 平台

Matrix 平台是一个 **多模型 LLM API 中转服务**。你只需一个 Token,就能在同一地址调用 Claude、GPT、Grok 等主流模型,用于 Claude Code、Codex 等 AI 编程工具,或直接通过 API 调用。

## 快速开始

只需三步即可开始使用:

<Steps>
  <Step title="注册并获取 Token">
    在 [Matrix 控制台](https://matrix.000328.xyz/dashboard) 注册账号,创建一个以 `sk-` 开头的 API Token。
    详见 [获取 Token](/getting-token)。
  </Step>
  <Step title="选择要用的模型">
    查看 [模型与定价](/models/overview),了解每个模型的特点和价格,选一个适合你的。
  </Step>
  <Step title="配置到客户端">
    把 Token 配置到 Claude Code、Codex 等客户端。详见 [客户端配置](/cli-config/env-check)。
  </Step>
</Steps>

## 关键信息

在使用 Token 时,你需要以下信息:

| 参数 | 值 |
| --- | --- |
| **Base URL** | `https://matrix.000328.xyz` |
| **API Key** | 你创建的 Token(`sk-xxx`) |

> **提示**:Base URL 不带 `/v1`,客户端会自动补全。
