## 怎么选模型

### 按需求选

| 你的需求 | 推荐模型 | 理由 |
| --- | --- | --- |
| 日常对话、省钱跑量 | `grok-3-mini-fast` / `gpt-5.4-mini` | 又快又便宜 |
| 复杂推理、数学、算法 | `gpt-5.5` / `grok-4.20-reasoning` | 推理能力强 |
| 编程写代码 | `gpt-5.5` / `claude-opus-4-8` | 代码能力顶级 |
| 长文档分析 | `claude-opus-4-8` | 长上下文王者 |
| 创意写作 | `grok-composer-2.5-fast` | 创作向优化 |
| 生图 | `grok-imagine-image-quality` | 高质量图片 |
| 生视频 | `grok-imagine-video` | 唯一视频选项 |

### 按成本选(从低到高)

```
便宜 ◀────────────────────────────▶ 贵
grok-3-mini-fast  gpt-5.4-mini  grok-3-mini
grok-composer-2.5-fast  grok-4.20-non-reasoning  gpt-5.4
grok-4.20-reasoning  claude-sonnet-4-6
grok-4.3  gpt-5.5  claude-opus-4-8  (旗舰,贵)
```

## 定价机制

Matrix 的计费分两类:

**按量计费(Token 计费)**:大多数对话模型。费用 = 输入 token + 输出 token × 输出倍率。控制台「定价」页面可查看每个模型的倍率。

**按次计费(固定价格)**:图片和视频生成模型。每次调用扣固定费用,与 token 无关。

| 模型 | 计费方式 | 单价 |
| --- | --- | --- |
| `grok-imagine-image` | 按次 | $0.022 / 张 |
| `grok-imagine-image-quality` | 按次 | $0.08 / 张 |
| `grok-imagine-video` | 按次 | $10 / 个 |
| 其他对话模型 | 按 token | 见控制台定价页 |

<Note>
  实际扣费还会乘以你所在**分组**的倍率(如 Gpt 组 3 折、Claude 组 4 折等),最终价格以控制台显示为准。
</Note>
