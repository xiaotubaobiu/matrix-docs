Matrix 平台支持多种登录方式。

## 密码登录

1. 访问 [Matrix 控制台](https://matrix.000328.xyz)
2. 输入注册时使用的邮箱和密码
3. 点击「登录」

<!-- 截图占位：密码登录界面 -->

## Authentik SSO 登录

如果你的组织已接入 Authentik 单点登录：

1. 访问 [Matrix 控制台](https://matrix.000328.xyz)
2. 点击「使用 SSO 登录」或第三方登录按钮
3. 跳转到 Authentik 登录页面
4. 输入你的组织账号凭据
5. 授权后自动跳转回 Matrix

<!-- 截图占位：SSO 登录界面 -->

<Note>
  SSO 登录后，你的 Matrix 账号会自动与组织账号关联，无需单独注册。
</Note>
