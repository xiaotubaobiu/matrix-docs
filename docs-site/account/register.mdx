## 注册流程

1. 访问 [Matrix 控制台](https://matrix.000328.xyz/dashboard)
2. 点击「注册」或「Sign Up」
3. 填写注册信息：
   - **邮箱**：用于登录和接收通知
   - **用户名**：你的显示名称
   - **密码**：设置一个安全密码
4. 点击「注册」完成

<Note>
  如果你的组织使用 Authentik SSO，你可以直接通过 SSO 登录而无需单独注册。参考 [登录方式](/account/login)。
</Note>

## 注册后

注册成功后，你可以：

- 登录 [LobeHub 聊天服务](https://lobehub.000328.xyz)
- 创建 [API Token](/token-service/getting-started) 用于客户端配置
- 使用 [图片生成 MCP](/mcp/image-generation)
