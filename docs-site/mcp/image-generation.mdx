Matrix Image MCP 是一个基于 MCP（Model Context Protocol）协议的图片生成工具。它允许你在 Claude Code 等支持 MCP 的客户端中直接生成图片。

## 什么是 MCP

MCP（Model Context Protocol）是一种让 AI 工具调用外部服务的协议。你可以把它理解为 AI 的「插件系统」。

## 功能

- 根据文字描述生成图片
- 支持多种图片尺寸
- 图片自动保存到本地

## 配置方法

在你的 MCP 配置文件中添加以下内容：

**Claude Code 配置**（`~/.claude/mcp.json` 或项目级 `.claude/mcp.json`）：

```json
{
  "mcpServers": {
    "matrix-image-mcp": {
      "type": "http",
      "url": "https://matrix.000328.xyz/mcp",
      "headers": {
        "Authorization": "Bearer sk-你的Token"
      }
    }
  }
}
```

<Note>
  具体的 URL 和配置方式可能因部署环境不同而有差异。请联系管理员获取最新的 MCP 端点地址。
</Note>

## 使用示例

配置完成后，在 Claude Code 中直接用自然语言描述你想生成的图片：

```text
帮我生成一张 1024x1024 的猫咪图片
```

```text
生成一个科技感的 logo，蓝色调，512x512
```

## 支持的参数

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| **prompt** | 图片描述（必填） | — |
| **size** | 图片尺寸 | `1024x1024` |
| **quality** | 图片质量 | `standard` |
| **model** | 使用的模型 | `gpt-image-2` |
