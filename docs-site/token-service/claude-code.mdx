---
title: "Claude Code 配置"
description: "在 Claude Code 中配置 Matrix Token"
---

Claude Code 是 Anthropic 官方的命令行 AI 编程助手。通过配置 Matrix Token，你可以使用 Matrix 的 API 服务。

## Linux / macOS

### 1. 安装 Claude Code

```bash
npm install -g @anthropic-ai/claude-code
```

### 2. 配置环境变量

在 shell 配置文件（`~/.bashrc`、`~/.zshrc` 或 `~/.bash_profile`）中添加：

```bash
export ANTHROPIC_API_KEY="sk-你的Token"
export ANTHROPIC_BASE_URL="https://matrix.000328.xyz:2053"
```

保存后重新加载配置：

```bash
source ~/.bashrc  # 或 ~/.zshrc
```

### 3. 验证

```bash
claude
```

如果配置正确，Claude Code 会正常启动并进入交互界面。

## Windows

### 1. 安装 Claude Code

```powershell
npm install -g @anthropic-ai/claude-code
```

### 2. 配置环境变量

**方法 A：PowerShell 永久设置**

```powershell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-你的Token", "User")
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://matrix.000328.xyz:2053", "User")
```

设置后重新打开终端窗口。

**方法 B：图形界面设置**

1. 按 `Win + R`，输入 `sysdm.cpl`，回车
2. 点击「高级」→「环境变量」
3. 在「用户变量」中点击「新建」：
   - 变量名：`ANTHROPIC_API_KEY`，变量值：`sk-你的Token`
   - 变量名：`ANTHROPIC_BASE_URL`，变量值：`https://matrix.000328.xyz:2053`
4. 确定保存，重新打开终端

### 3. 验证

```powershell
claude
```

## 常见问题

<Accordion>
  <AccordionItem title="连接超时或无法访问">
    检查网络是否能访问 `https://matrix.000328.xyz:2053`。如果使用代理，确保代理配置正确。
  </AccordionItem>
  <AccordionItem title="提示 API Key 无效">
    确认 Token 以 `sk-` 开头且没有多余空格。重新复制 Token 再试。
  </AccordionItem>
  <AccordionItem title="环境变量没有生效">
    Windows 用户设置后需要重新打开终端。Linux/macOS 用户需要 `source` 配置文件或新开终端。
  </AccordionItem>
</Accordion>
