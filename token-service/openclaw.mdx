OpenClaw 是一个开源的 AI 编程助手客户端。通过配置 Matrix Token，你可以使用 Matrix 的 API 服务。

## Linux / macOS

### 1. 安装 OpenClaw

参考 [OpenClaw 官方文档](https://github.com/openclaw) 获取最新安装方式。

### 2. 配置 API 连接

在 OpenClaw 的配置文件或设置界面中填入：

| 设置项 | 值 |
| --- | --- |
| **API Base URL** | `https://matrix.000328.xyz` |
| **API Key** | `sk-你的Token` |

或通过环境变量设置：

```bash
export OPENCLAW_API_KEY="sk-你的Token"
export OPENCLAW_BASE_URL="https://matrix.000328.xyz"
```

### 3. 验证

启动 OpenClaw 并尝试发送一条消息，确认能正常响应。

## Windows

### 1. 安装 OpenClaw

参考 OpenClaw 官方文档的 Windows 安装说明。

### 2. 配置 API 连接

```powershell
[System.Environment]::SetEnvironmentVariable("OPENCLAW_API_KEY", "sk-你的Token", "User")
[System.Environment]::SetEnvironmentVariable("OPENCLAW_BASE_URL", "https://matrix.000328.xyz", "User")
```

或通过图形界面设置（参考 [Claude Code Windows 配置](/token-service/claude-code)）。

设置后重新打开终端。

### 3. 验证

启动 OpenClaw 并尝试发送一条消息。
